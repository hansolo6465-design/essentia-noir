# Essentia Noir - Luxury Perfume Brand Website

A premium, fully-animated perfume brand website built with modern web technologies.

## 🌟 Features

- **Premium UI/UX Design** - Clean, luxurious, and modern aesthetic
- **3D Animations** - Interactive 3D perfume bottles using Three.js
- **Smooth Animations** - GSAP ScrollTrigger animations throughout
- **Fully Responsive** - Works perfectly on desktop, tablet, and mobile
- **Interactive Elements** - Hover effects, ripple buttons, smooth scrolling
- **Premium Logo** - Custom SVG gradient perfume bottle logo
- **Product Showcase** - Featured collections with 3D product visualization
- **Contact & Newsletter** - Fully functional forms
